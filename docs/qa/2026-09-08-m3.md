## Écarts et réserves explicites

1. Le seuil Lighthouse quatre axes est atteint sur le build local. Il n’est PAS atteint sur la preview : `X-Robots-Tag: noindex` explique le SEO 69. Ce garde-fou de prévisualisation n’a pas été retiré. Le beacon Cloudflare provoque des erreurs CORS et réduit les bonnes pratiques à 96. Ne pas présenter la preview comme quatre scores >=95.
2. La politique de confidentialité ne nie plus l’analytics injecté ; finalités mises en cohérence. Validation juridique humaine avant publication, notamment bases légales/durées/transferts hérités, hors audit juridique M3.
3. Blog vide : avertissements Astro attendus. Le hint Lighthouse est informatif, aucune erreur de typage.
4. Le titre SEO historique reste conservé à la demande, malgré sa tension avec le nouveau positionnement ; arbitrage éditorial en M3-R si Kevin souhaite le changer.
5. Images définitives M4 ; aucun nom ni donnée client réelle ajouté.
6. Les tests utilisent un serveur preview déjà lancé (commande documentée). `QA_URL` permet de tester le déploiement exact.
7. La configuration Git-build Cloudflare reste celle de l’ancienne landing : à l’intégration autorisée, régler `npm run build` et `dist`, jamais déployer la racine.
