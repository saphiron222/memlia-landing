# Recette technique de la garde de release SEO

Ce fichier sert uniquement à éprouver le périmètre seo-measures d'une PR d'essai.
Il ne contient aucune mesure de trafic, de classement, de citation ou de performance.
La PR d'essai n'est pas destinée à être fusionnée ni à publier un relevé.

Comportement attendu : CI verte et revue QA indépendante PASS permettent un verdict
positif sans reçu opérateur Telegram. L'absence de QA PASS ou une CI rouge doivent
refuser la release. La garde reste en lecture seule et ne fusionne rien.
