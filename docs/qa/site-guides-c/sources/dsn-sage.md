# Reprendre les contrats sociaux dans la DSN

## Summary

Cette fiche est une foire aux questions les plus posées autour des contrats sociaux dans la DSN sur Sage Paie et Sage 100 Paie & RH

## Resolution

1\. **Comment éditer les contrats sociaux des salariés présents ?**

Depuis la liste des salariés faire un clic droit 'Editer' sur la liste des salariés et cocher 'Contrat'.

Par le bouton 'Sélection manuelle', faire un tri sur la colonne 'E' et ne choisir que les salariés présents. En édition, les contrats sociaux salariés sont proposés.

2\. **Mise à jour des contrats sociaux non prise en compte dans Sage DS**

Vérifier dans un premier temps l’option « A déclarer DSN » dans les contrats sociaux (Listes / contrats sociaux).

Lors de mise à jour de contrats sociaux (modification de référence par ex), la modification du contrat ne remonte pas en DSN mensuelle. Il est nécessaire de réaliser un transfert DSN sur une plage de date au moins équivalente à celle du contrat social afin de mettre à jour la base DS.

3\. **Gestion du code option et code population de rattachement sur le contrat social**

Si en fiche de personnel le champ « Code option retenue par les salariés » est vide, alors en DSN on prend le champ « Code option retenue par les salariés » DSN du contrat société.

Si en FP le champ « Code population de rattachement » est vide, alors en DSN on reprend le champ « Code population de rattachement » DADS-U de contrat société.
