## Contrat commun des cinq fiches

Produit entier gratuit, sans compte, sans inscription ni courriel pour exporter. Démonstration fictive chargeable, import/saisie, résultat explicable, correction, commentaires préservés, export puis réimport du travail : l'utilisateur doit pouvoir reprendre une mission sans stocker ses données sur le site. Session en mémoire ; effacement explicite. Aucune donnée traitée dans URL, réseau, télémétrie, logs ou stockage persistant. La page peut charger ses assets locaux avant usage ; CSP connect-src none pour le traitement, dépendances/polices auto-hébergées. Tester les requêtes après chargement et les stockages, pas seulement inspecter le code.

Formats décidés : CSV UTF-8 BOM compatible tableur, JSON de reprise versionné, rapport HTML imprimable pour le dossier. Pas de XLSX promis dans le premier lot. Import CSV tabulation/point-virgule/virgule explicites, prévisualisation et mapping avant traitement ; conserver les identifiants et zéros initiaux. Décimaux exacts ; unités et conventions de signe visibles. CSV de sortie neutralise les cellules susceptibles de formule ; JSON conserve la donnée source. Fichiers de données : plafond 20 Mo par fichier et 100 000 lignes, Worker annulable ; un résultat arrêté reste incomplet et non exportable comme complet. Pagination d'affichage sans tronquer le total ni l'export. Contenu injecté en texte, noms de fichiers nettoyés, pas de HTML actif issu de l'import.

Chaque export de dossier contient : entrées retenues, paramètres, méthode, version de l'outil, date réelle de génération, contrôles exécutés et limites, référence de mission facultative, préparateur/réviseur saisis volontairement. Rien n'attribue une validation à un humain qui n'a pas validé. Fournir aussi une fiche outil imprimable méthode/version/limites/jeux de tests, utile à l'appréciation de l'outil par le CAC, sans déclarer cette appréciation accomplie par le téléchargement.

Design : Outil.astro et sections/tokens existants, Fraunces/Hanken/Picto, navigation mobile visible, tableau exploitable au clavier, erreurs liées aux champs, focus visible, annonces de traitement, annulation et export accessibles. Reflow 400 %, reduced-motion, six largeurs 320/375/768/1024/1440/1920 ; captures pleine page 375 et 1440 comparées au gabarit historique. Une scène HTML figée propre par outil, jeu fictif réellement calculé, renderer du dépôt : 1600×900, WebP <150 Ko et OG 1200×630 ; aucune image recyclée. Méthode HTML et contrat de contenu du skill memlia-site-design.

SEO : une route par besoin, canonical absolu sans slash terminal, H1 intent-first et OG/headline identiques, description unique, WebPage/WebApplication/BreadcrumbList véridiques, footer/sitemap/hub depuis les collections. Promouvoir uniquement la route rendue dans page-intent-contract ; garder les primaires de C3. Les pages/articles projetés ne sont pas encore des liens entrants réels. Chaque publication exige trois liens depuis des pages indexables disponibles, dont le hub ; si les articles CAC prévus sont absents, employer les alternatives indiquées dans chaque fiche, avec ancre qui nomme le geste. Aucun lien vers une route absente.

Copy : valeur d'abord, frontière en trois colonnes (calcul/préparation seul ; paramètres/sources à valider ; décision professionnelle humaine), sources compactes. CTA « Confier une première tâche » vers /contact après le résultat, jamais pour déverrouiller. Kevin Kitanga est fondateur, pas CAC. Appliquer la charte courante de main, y compris sa v5 si fusionnée depuis ce cadrage.

QA pour les outils de transformation/calcul non normatif (1, 2, 4, 5), incluant la vérification des formulations bornées et des sources ; metier pour le barème dont la règle juridique constitue le résultat. Cette substitution à QA pour le barème évite une double revue et suit la constitution ; dev reste responsable de ses tests techniques.
