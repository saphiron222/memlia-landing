# Inventaires navigateur

Les recettes glossaire et intégrations importent les données de production. Les nombres historiques restent des planchers ; les identités et lettres sont comparées exactement. Les moyeux viennent de service.href. Tous les guides sont parcourus aux six largeurs et sans JavaScript.

inventory-extensibility.spec.ts réutilise les mêmes assertions avec des fixtures isolées : terme et initiale supplémentaires, absence et substitution, guide supplémentaire et routes invalides. Le guide fictif est une copie du HTML existant interceptée dans le navigateur, sans écriture ni publication.

Rejeu : npx playwright test tests/browser/glossary.spec.ts tests/browser/integrations.spec.ts tests/browser/inventory-extensibility.spec.ts

L’attribut JSON de integrations.ts permet son import par Playwright ; les lecteurs de sources Node/Python chargent ce même inventaire local avant compilation.
