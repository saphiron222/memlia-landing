				(function () {
			try {
				var stored = localStorage.getItem('theme');
				var theme = /^(light|dark|high-contrast)$/.test(stored)
					? stored
					: matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light';

			<script id="atlas-layout-preferences">
				(function () {
			try {
				var state = JSON.parse(localStorage.getItem('atlas-layout-preferences') || '{}');
				var view = state["docs-layout-persistence"] || {};
				var excludesKey = "";
				var blocked = {};
				if (excludesKey) {
					var exclusions = JSON.parse(localStorage.getItem('atlas-layout-exclusions') || '{}');
					if (Object.prototype.hasOwnProperty.call(exclusions, excludesKey)) {
						var scoped = exclusions[excludesKey];
						if (scoped) {
							if (typeof scoped === 'object') blocked = scoped;
						}
					}
				}
				var html = document.documentElement;
				for (var c in view) {
					if (Object.prototype.hasOwnProperty.call(blocked, c)) continue;
					if (view[c]) html.classList.add(c);
					else html.classList.remove(c);
				}
			} catch (e) {}
		})();;
			</script>

	 <div class="content"><p>Utilisez la plateforme des compléments Office pour créer des solutions qui étendent des applications Office et interagissent avec du contenu dans des documents Office. En utilisant Compléments Office, vous pouvez utiliser des technologies web familières telles que HTML, CSS et JavaScript pour étendre Outlook, Excel, Word, PowerPoint, OneNote et Project et interagir avec eux. Votre solution peut s’exécuter dans Office sur plusieurs plateformes, notamment Windows, Mac, iPad et dans un navigateur.</p>
<div class="IMPORTANT">
<p>Importante</p>
<p>Un complément peut avoir l’un des deux types de manifestes. Cet article part du principe que le complément utilise le type recommandé pour la plupart des scénarios : le manifeste unifié pour Microsoft 365. Pour plus d’informations sur les deux types, voir <a href="../develop/add-in-manifests" data-linktype="relative-path">Manifeste des compléments Office</a>.</p>
</div>
<p>
              <span class="mx-imgBorder">
              <img src="../images/addins-overview.png" alt="L’application Office et un site web intégré (complément) offrent des possibilités d’extensibilité infinies." data-linktype="relative-path">
              
              </span>
            
</p>
<p>Vous pouvez utiliser la plateforme des compléments Office pour&nbsp;:</p>
<ul>
<li><p>
              <strong>Ajouter de nouvelles fonctionnalités aux clients Office</strong> : importez des données externes dans Office, automatisez des documents Office, exposez des fonctionnalités de Microsoft et d’autres dans les clients Office, et bien plus encore. Par exemple, vous pouvez utiliser l’API Microsoft Graph pour établir une connexion vers des données qui améliorent la productivité.</p>
</li>
<li><p>
              <strong>Créer des agents Copilot personnalisés qui lisent et écrivent dans des documents ouverts dans les applications Office (préversion)</strong> - Permettez à vos utilisateurs d’utiliser le langage naturel pour accéder aux fonctionnalités de votre complément.</p>
</li>
<li><p>
              <strong>Créer de nouveaux objets interactifs et enrichis qui peuvent être incorporés dans des documents Office :</strong> vous pouvez incorporer des cartes, des graphiques et des visualisations interactives que les utilisateurs peuvent ajouter à leurs feuilles de calcul Excel et présentations PowerPoint.</p>
</li>
</ul>
<h2 id="components-of-an-office-add-in">Composants d’un complément Office</h2>
<p>Un complément Office comprend deux composants de base : un package d’application et votre propre application web. Le package inclut un manifeste qui définit différents paramètres, notamment l’intégration de votre complément aux clients Office. Votre application web doit être hébergée sur un serveur web ou un service d’hébergement web, tel que Microsoft&nbsp;Azure.</p>
<h3 id="app-package">Package de l’application</h3>
<p>Le package d’application d’une application pour Microsoft 365 est un fichier zip contenant un fichier manifeste, deux icônes d’application et éventuellement des fichiers de configuration ou de localisation supplémentaires. La logique de votre application et le stockage des données sont hébergés ailleurs et accessibles par l’application hôte Microsoft 365 via HTTPS. Vous devez envoyer le package d’application à votre administrateur pour publication dans votre organisation ou à l’Espace partenaires pour publication sur la Place de marché Microsoft.</p>
<p>Pour obtenir une vue d’ensemble détaillée du package d’application, consultez <a href="app-package-for-microsoft-365" data-linktype="relative-path">Package de l’application pour Microsoft 365</a>.</p>
<h4 id="manifest">Manifeste</h4>
<p>Le manifeste spécifie les paramètres et les fonctionnalités du complément, par exemple :</p>
<ul>
<li><p>Le nom d’affichage, la description, l’ID, la version et les paramètres régionaux par défaut du complément.</p>
</li>
<li><p>La façon dont le complément s’intègre à Office.</p>
</li>
<li><p>Comment le complément s’intègre à Copilot (préversion).</p>
</li>
<li><p>Le niveau d’autorisation et les conditions d’accès aux données pour le complément.</p>
</li>
</ul>
<p>Pour obtenir une vue d’ensemble détaillée du manifeste, voir <a href="../develop/unified-manifest-overview" data-linktype="relative-path">Compléments Office avec le manifeste d’application unifiée pour Microsoft 365</a>.</p>
<h3 id="web-app">Application web</h3>
<p>Le complément Office le plus simple consiste en une page HTML statique qui s’affiche dans une application Office, mais n’interagit pas avec le document Office ou toute autre ressource Internet. Toutefois, pour créer une expérience qui interagit avec les documents Office ou permet à l’utilisateur d’interagir avec des ressources en ligne à partir d’une application cliente Office, vous pouvez utiliser toutes les technologies, côté client et côté serveur, prises en charge par votre fournisseur d’hébergement (comme ASP.NET, PHP ou Node.js). Pour interagir avec les clients et les documents Office, utilisez les API JavaScript Office.js.</p>
<p>
              <span class="mx-imgBorder">
              <img src="../images/about-addins-componentshelloworldoffice.png" alt="Composants d’un complément Hello World." data-linktype="relative-path">
              
              </span>
            
</p>
<h2 id="extending-and-interacting-with-office-clients">Extension des clients Office et interaction avec ces clients</h2>
<p>Au sein d’une application cliente Office, les compléments Office peuvent effectuer les tâches suivantes :</p>
<ul>
<li><p>Étendre les fonctionnalités</p>
</li>
<li><p>Suivre les instructions en langage naturel à partir de Copilot (préversion)</p>
</li>
<li><p>Créer des objets (Excel ou PowerPoint uniquement)</p>
</li>
</ul>
<h3 id="extend-office-functionality">Étendre les fonctionnalités d’Office</h3>
<p>Vous pouvez ajouter de nouvelles fonctionnalités aux applications Office via les fonctionnalités suivantes :</p>
<ul>
<li><p>Boutons de ruban et commandes de menu personnalisés (collectivement appelés « commandes de complément »).</p>
</li>
<li><p>Volets Office pouvant être insérés avec un contrôle WebView qui peut faire presque tout ce qu’une page Web peut faire dans un navigateur.</p>
</li>
<li><p>Gestionnaires d’événements qui répondent aux événements dans le document ou l’application Office.</p>
</li>
</ul>
<p>L’interface utilisateur personnalisée, les volets de tâches et les gestionnaires d’événements sont spécifiés dans le manifeste du complément.&nbsp;&nbsp;</p>
<h4 id="custom-buttons-and-menu-commands">Commandes de menu et boutons personnalisés</h4>
<p>Vous pouvez ajouter des boutons et des options de menu personnalisés au ruban dans Office sur le web et sur Windows. Les utilisateurs peuvent ainsi accéder à votre complément directement à partir de leur application Office. Les boutons et les éléments de menu personnalisés peuvent lancer différentes actions, telles que l’affichage d’un volet Office avec HTML personnalisé ou l’exécution d’une fonction JavaScript.</p>
<p>
              <span class="mx-imgBorder">
              <img src="../images/about-addins-addincommands.png" alt="Boutons personnalisés et commandes de menu." data-linktype="relative-path">
              
              </span>
            
</p>
<h4 id="task-panes">Volets de tâches</h4>
<p>Vous pouvez utiliser des volets Office en plus des commandes de complément pour permettre aux utilisateurs d’interagir avec votre solution. Dans Excel, Word et PowerPoint, les utilisateurs lancent les compléments du volet Office via le bouton <strong>Compléments d’accueil</strong>&gt;.<strong></strong> Dans Outlook, les utilisateurs lancent les compléments du volet Office via le bouton « Complément » ou via le bouton <strong>« Toutes les applications</strong> » du ruban.</p>
<p>
              <span class="mx-imgBorder">
              <img src="../images/about-addins-taskpane.png" alt="Utilisez des volets de tâches en plus des commandes de complément." data-linktype="relative-path">
              
              </span>
            
</p>
<h3 id="extend-outlook-functionality">Extension des fonctionnalités Outlook</h3>
<p>Les utilisateurs peuvent exécuter des compléments Outlook lorsqu’ils affichent, répondent ou créent des courriers électroniques, des demandes de réunion, des réponses aux réunions, des annulations de réunions ou des rendez-vous. Les compléments Outlook peuvent effectuer les tâches suivantes :</p>
<ul>
<li>Étendre le ruban de l’application Office.</li>
<li>Afficher contextuellement en regard d’un élément Outlook lorsque vous l’affichez ou le composez.</li>
<li>Effectuez une tâche lorsqu’un événement spécifique se produit, par exemple lorsqu’un utilisateur crée un message.</li>
</ul>
<div class="NOTE">
<p>Remarque</p>
<p>Les compléments qui interagissent avec le calendrier, les réunions ou les rendez-vous de l’utilisateur sont disponibles uniquement si l’utilisateur ouvre le calendrier dans Outlook et non dans Teams. Toutefois, vous pouvez créer une application de réunion Teams et l’afficher dans Outlook. Pour plus d’informations, consultez <a href="/fr-fr/microsoftteams/platform/m365-apps/extend-m365-meeting-app" data-linktype="absolute-path">Étendre une application de réunion Teams à Outlook</a>.</p>
</div>
<p>Pour accéder à une vue d’ensemble des compléments Outlook, reportez-vous à la rubrique <a href="../outlook/outlook-add-ins-overview" data-linktype="relative-path">Présentation des compléments Outlook</a>.</p>
<h3 id="create-new-objects-in-office-documents">Création d’objets dans des documents Office</h3>
<p>Vous pouvez incorporer des objets web, appelés compléments de contenu, dans des documents Excel et PowerPoint. Ces compléments de contenu vous permettent d’intégrer des visualisations de données web enrichies, du contenu multimédia (comme un lecteur vidéo YouTube ou une galerie d’images) et d’autres types de contenu externe.</p>
<p>
              <span class="mx-imgBorder">
              <img src="../images/about-addins-contentaddin.png" alt="Incorporer des objets web appelés compléments de contenu." data-linktype="relative-path">
              
              </span>
            
</p>
<h2 id="office-javascript-apis">API JavaScript pour Office</h2>
<p>Les API JavaScript Office sont composées d’objets et de membres permettant de créer des compléments et d’interagir avec le contenu Office et les services&nbsp;web. Il existe un modèle objet commun partagé par Excel, Outlook, Word, PowerPoint, OneNote et Project. Il existe également des modèles objets spécifiques aux applications plus complets pour Excel, OneNote, PowerPoint et Word. Ces API permettent d’accéder à des objets connus tels que des paragraphes et des classeurs, ce qui facilite la création d’un complément pour une application spécifique.</p>

<h2 id="how-are-office-add-ins-different-from-com-and-vsto-add-ins">En quoi les compléments Office sont-ils différents des compléments COM et VSTO ?</h2>
<p>Les compléments COM et VSTO sont des solutions d’intégration Office antérieures qui s’exécutent uniquement dans Office sur Windows. Contrairement aux compléments COM et VSTO, les compléments Office sont des compléments web : l’application (par exemple, Excel) lit le manifeste du complément et connecte les boutons de ruban personnalisés et les commandes de menu du complément dans l’interface utilisateur. Le cas échéant, le code JavaScript et HTML du complément, qui s’exécute dans le contexte d’un navigateur ou d’un contrôle WebView dans un bac à sable.</p>
<p>
              <span class="mx-imgBorder">
              <img src="../images/office-programmability-diagram.png" alt="Diagramme à quatre quadrants montrant les domaines d’intérêt des différentes solutions d’extensibilité Office. Les compléments web Office ainsi que les compléments COM et VSTO ciblent les développeurs professionnels, tandis que VBA cible les utilisateurs finaux. Les compléments Office Web sont axés sur les expériences multiplateformes et la collaboration, tandis que les compléments COM et VSTO et VBA répondent à l’expérience de l’individu sur Windows." data-linktype="relative-path">
              
              </span>
            
</p>
<p>Les compléments Office offrent les avantages suivants par rapport aux compléments créés à l’aide de VBA, COM ou VSTO.</p>
<ul>
<li><p>Prise en charge multiplateforme : Les compléments Office s’exécutent dans Office sur le web, Windows, Mac et iPad.</p>
</li>
<li><p>Prise en charge des applications pour Microsoft 365 : Les compléments Office peuvent être empaquetés avec d’autres extensions Microsoft 365, telles que les applications Teams et les agents Copilot pour le déploiement en tant qu’une seule unité.</p>
</li>
<li><p>Déploiement et distribution centralisés : les administrateurs peuvent déployer Compléments Office de manière centralisée au sein d’une organisation.</p>
</li>
<li><p>Accès facile via Microsoft Marketplace : Vous pouvez mettre votre solution à la disposition d’un large public en l’envoyant sur Microsoft Marketplace.</p>
</li>
<li><p>Basé sur la technologie web standard : Vous pouvez utiliser la bibliothèque de votre choix pour créer des compléments Office.</p>
</li>
</ul>
<div class="IMPORTANT">
<p>Importante</p>
<p>Les compléments COM et VSTO ne sont pas pris en charge dans le <a href="https://support.microsoft.com/office/656bb8d9-5a60-49b2-a98b-ba7822bc7627" data-linktype="external">nouvel Outlook sur Windows</a>. Ces compléments sont toujours pris en charge dans le client de bureau Outlook sur Windows classique. Pour plus d’informations, voir <a href="../outlook/one-outlook" data-linktype="relative-path">Développer des compléments Outlook pour la nouvelle version d’Outlook sur Windows</a>.</p>
</div>
