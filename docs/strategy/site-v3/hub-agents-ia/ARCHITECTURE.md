## 6. Contact : recommandation `sessionStorage` à usage unique + liste blanche (pas `?tache=`)

**Pourquoi pas `?tache=`.** 27 puces de départ (9 fiches × 3) créeraient 27 URL `/contact?tache=…` explorables ; l'identifiant partirait dans les journaux de bord ; `cheminInterne` (`functions/api/contact.js:~40-48`) et la politique (`politique-de-confidentialite.astro:52`, « sans paramètres ni ancre ») sont écrites pour des chemins sans requête.
