## Ordre commercial observé

Outils-EC répète une séquence efficace : tâche et résultat dans le héros ; tableau illustrant le portefeuille ; coût de la répétition manuelle ; solution et livrables ; fonctionnement ; comparaison ; questions pratiques ; réassurance ; offre et robots voisins. Les tableaux simulés, compteurs de rendement et affirmations d’exhaustivité ne deviennent pas des preuves Memlia. Nous conservons la progression de compréhension dans le gabarit agents validé : promesse → exemple fictif → pièces remises → règle de fonctionnement → exceptions → questions de démarrage.

## Objections et réponses de service

`OBJECTIONS.md` projette, robot par robot, les objections en réponses Memlia et leur emplacement exact. Les hypothèses techniques restent ici : environnement d’exécution et planification définis à l’installation ; comptes et habilitations prévus ; authentification non contournée ; conventions de classement et reprises écrites ; recette sur cas fictifs ; changements de portail traités dans le périmètre de maintenance. Le devis tient compte de ces éléments. Nous ne promettons ni installation le jour même, ni stockage exclusivement local, ni accès unique à tous les portails, ni volume ou rendement fixe.
