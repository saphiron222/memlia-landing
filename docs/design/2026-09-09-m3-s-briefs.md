# M3-S : direction et registre visuel courant

Statut : proposition à valider. Base M3-R 76f174d.

## Lecture design

Landing B2B pour cabinets d’expertise comptable, sobre et rassurante, évolution narrative du système Navattic → Memlia. DESIGN_VARIANCE 4, MOTION_INTENSITY 4, VISUAL_DENSITY 4. CSS natif Astro ; charte claire, Fraunces/Hanken, crème/encre/vert, rayons et mouvements M2 préservés. Pas de refonte esthétique ni de génération payante en M3-S : M4 possède les images définitives. Les presets génériques des skills ne remplacent pas cette décision de préservation.

## Narration retenue

Hero → problème quotidien → résultat livré → cinq usages illustratifs → méthode → intégration aux outils → contrôle humain → garanties → FAQ → prise de contact. H1 : « Automatisez les tâches qui ralentissent votre cabinet. » CTA partout : « Identifier une tâche à automatiser ». Excel est un exemple d’intégration, jamais le hero ni la catégorie.

## Limites de cette phase

Les emplacements rayés IMG-NN sont intentionnels. Ils ne prouvent ni un produit ni une intégration livrée. Les sources historiques Modules.astro et modules.ts restent non importées ; leurs styles et anciens sélecteurs inutilisés sont signalés, pas nettoyés hors périmètre. M4 remplace les images ; M5 ajoute le blog. Aucun changement des textes juridiques sans validation humaine.
