# Retrouver les étapes pour paramétrer la clôture d'un exercice (Guide TDFA)

Created on 06 January 2021 \| Last modified on 31 October 2024

## Summary

Cette fiche propose une documentation reprenant en détail toutes les étapes d'une clôture réussie dans Sage 100 Comptabilité.

## Description

Retrouvez dans cette documentation les différentes étapes pour la clôture d'un exercice ainsi que les questions les plus fréquentes :

#### Les différentes étapes pour la clôture d'un exercice

- Contrôle des données comptables
- Intégration des écritures comptables
- Sauvegarde de la base de données
- Sauvegarde fiscale des données
- Clôture totale des journaux
- Création d'un nouvel exercice
- Génération des reports à nouveaux définitifs
- Clôture de l'exercice
- Génération du fichier d'écritures pour la DGFIP (fichier FEC).

#### Questions les plus fréquentes

- Quel est le délai de conservation ?
- Comment lettrer en automatique sur plusieurs tiers en même temps ?
- Comment générer les reports à nouveaux des comptes tiers en solde et non en détail ?
- Est-il possible de générer plusieurs fois les reports à nouveaux ?
- Comment régénérer les reports à nouveaux ?
- Est-il possible de saisir des écritures sur l'exercice précédent alors que les à nouveaux ont déjà été générés sur l'exercice suivant ?
- Comment vérifier que le résultat présent dans le journal des à nouveaux est correct ?
- Que vérifier si le rapprochement bancaire n'est plus correct sur le nouvel exercice ?
- Que doit-on faire avec les écritures de situation ?
- Pourquoi le journal de caisse refuse-t-il de se clôturer ?
- Comment purger les extraits de comptes bancaires ?
- Comment supprimer le premier exercice ?
